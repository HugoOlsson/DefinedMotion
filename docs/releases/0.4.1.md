# DefinedMotion 0.4.1

Dependency maintenance update with refreshed XML handling and supporting dependencies.

- Includes the tested math-rendering dependencies for consistent npm installations.
- Updates the project generator to use DefinedMotion 0.4.1.
- No changes to the public animation API or scene format.

Update an existing project:

```bash
npm install definedmotion@0.4.1
```

Create a new project:

```bash
npx create-definedmotion@0.4.1 my-animation
```
