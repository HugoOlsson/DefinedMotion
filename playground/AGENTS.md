# DefinedMotion playground

This is a private consumer project used while developing DefinedMotion. Scenes and assets here are
never included in the npm package. Promote durable learning material into
`packages/definedmotion/reference/examples` or `packages/definedmotion/reference/tests`.

Follow `../packages/definedmotion/reference/agent-workflow.md` when editing an animation.

Use `src/scenes` and `src/assets` exactly as a generated consumer project would. Keep builds,
automation output, and runtime state under `.definedmotion/`, and final videos under `renders/`;
neither directory is published or committed.
